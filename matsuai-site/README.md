# 松合ホームページ(骨組み)

熊本県宇城市不知火町松合の、白壁土蔵の町を紹介するサイトの骨組みです。
動く最低限の仕組みだけが入っていて、細かい見た目や演出は `TODO` として残してあります。

## フォルダの中身

```
matsuai-site/
├── index.html      トップ(漆喰を塗る画面)
├── doors.html      蔵の扉をひらく(各ページの入口)
├── street.html     通りを歩く(360度)
├── css/
│   ├── common.css  全ページ共通(色・フォント・ヘッダー)
│   ├── top.css
│   ├── doors.css
│   └── street.css
├── js/
│   ├── top.js
│   ├── doors.js
│   └── street.js
└── images/
    ├── photos/     普通の写真(商品・料理・町並みなど)
    └── 360/        360度写真(いまは仮の画像が入っている)
```

## 動かし方

1. VS Code でこのフォルダを開く
2. 拡張機能「Live Server」を入れる
3. `index.html` を右クリック →「Open with Live Server」

※ 360度のページは、ファイルをダブルクリックで開くと写真が読み込めません。必ず Live Server で開いてください。

## 公開のしかた(GitHub Pages)

1. GitHub で新しいリポジトリ(Public)を作る
2. このフォルダの中身をすべてアップロードする
3. Settings → Pages → Branch を `main` にして保存
4. 数分後に `https://ユーザー名.github.io/リポジトリ名/` で見られる
